关于平台

AI 智能渗透测试评估控制台将传统渗透工具与 AI 代理融合：从 DNS、端口和指纹侦察，到漏洞验证与报告生成， 所有决策都由 Dify 工作流驱动的多智能体协同完成。

系统支持人机协作，可将结果推送到 MCP 或自定义的安全运营链路中， 让团队以更少人工处理更多高价值安全任务。

智能策略内核

根据目标画像与扫描反馈自动调整探测深度、顺序与验证方式，摆脱固定脚本式扫描。

自动化验证闭环

AI 生成验证命令并在 Kali 环境安全执行，输出置信度、误报与详细利用指南。

知识增强

侦察记录与参考资料写入 Dify「知识检索」节点，实现结果追溯与复用。

AI 能力矩阵

多智能体架构覆盖侦察、攻击面扩展、自动验证与知识回写，下面为核心能力列表：

侦察 · 信息收集

  • DNS / WHOIS / 子域名 / WAF
  • 端口扫描（Nmap）
  • 技术栈与 CMS 指纹识别

攻击面扩展

  • 目录路径探测，专项测试
  • Tomcat / Spring Boot / Jenkins 场景策略
  • 自动补充端口与敏感端点

AI 智能验证

  • 自动命令生成与安全执行
  • 实时置信度评估（高/中/低）
  • 产出利用指南与命令集

结果分类

真实漏洞、误报、待人工，三类输出让安全人员聚焦高优先级事件。

接口扩展

MCP Server、WebSocket 推送与数据库记录，让扫描进度与事件对外共享。

运行流程

AI 通过工作流驱动每个阶段的决策，形成“输入 → 策略 → 执行 → 回馈”的闭环。

01

任务启动：输入目标、场景（渗透 / 验证 / 情报复现）。

02

AI 策略编排：Dify Workflow 调度多代理，读取知识库上下文。

03

多阶段扫描：信息收集 → 端口 / 服务 → 指纹 → 漏洞探测。

04

AI 决策示例：识别 Tomcat 会补充 8009/8443、/manager、CVE-2020-1938；Spring Boot 直击 /actuator 与 Spring4Shell。

05

自动验证（可选）：AI 生成命令 → Kali 执行 → 回传日志。

06

结果分级：真实漏洞 / 误报 / 待人工，并附置信度与利用指南。

07

交付：HTML/JSON 报告、AI 验证日志、知识库增量同步到外部系统。

运行环境

控制台、Kali、Dify 与数据安全配置协同，确保 AI 驱动的渗透任务可控、可追溯。

本地控制台

  • Python 3.8+，Windows / Linux / macOS
  • MySQL 5.7+ 存储任务、漏洞与报告
  • 支持 Web 界面 & CLI 调度

Kali Linux

  • 远程或本地 Kali，需 SSH 访问
  • 必备工具：Nmap / Nuclei / Nikto / WhatWeb / Curl / Dig
  • 可执行 install_kali_tools.sh 一键安装

AI & Dify

  • Dify App Key、Base URL、workflow user、timeout
  • 知识库默认使用百度千帆，可替换为自定义向量存储
  • MCP Server & WebSocket 输出过程事件

数据与安全

  • 扫描记录写入知识检索节点，支持追溯
  • 全部密钥配置在环境变量，避免提交
  • 仅在获授权的目标系统上使用

快速开始

安装依赖

pip install -r requirements.txt

建议使用虚拟环境或容器，确保依赖隔离。

配置环境变量

DIFY_API_KEY=your-key
DIFY_API_BASE_URL=https://api.dify.ai/v1
KALI_HOST=your-kali-ip
DB_NAME=pentest_db

生产环境使用安全的密钥管理方式，例如 Vault 或 CI 密文。

准备 Kali

sudo apt update && sudo apt upgrade -y
sudo apt install -y nmap nikto whatweb curl dnsutils
go install github.com/projectdiscovery/nuclei/v2/cmd/nuclei@latest
nuclei -update-templates

运行方式：Web UI（python app.py）实时查看任务；或通过 MCP/CLI 将扫描与验证纳入自动化编排。
